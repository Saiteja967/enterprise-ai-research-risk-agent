# Contributor guide

Use Python 3.12+ and Node 22.12+ or 24. Keep all fixtures fictional. Run commands from the repository root unless a step specifies frontend/. Keep database mutations in human-requested operations and decision handlers. Agent tools must remain read-only, scoped and parameterized. Treat retrieved text and model outputs as untrusted. Update the evidence fixtures and evaluation expectations separately so a regression cannot update its own answer key. Run the checks in README.md before committing.
